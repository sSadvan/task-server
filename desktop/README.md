# Шар Джона на рабочем столе

Electron-приложение показывает анимированный шар из `../orb/` справа внизу, поверх
всех окон. Окно прозрачное и без рамки. Состояние шара переключает сам Джон через
локальный мост (`desktop/john/john_orb.py`).

## Запуск

```sh
cd desktop
npm install
npm start
```

- Иконка появляется в трее. В меню есть пункты «Показать / скрыть», «Разбудить»,
  «Уснуть», «Запускать при входе», «Панель разработчика» и «Выход».
- Галочка «Запускать при входе» включает автозапуск. На Windows и macOS он
  оформляется через вход в систему, на Linux через файл
  `~/.config/autostart/john-orb.desktop`.
- Второй экземпляр приложения не стартует.
- Горячая клавиша `Ctrl+Shift+Space` (на macOS `Cmd+Shift+Space`) будит шар. Клик
  по шару делает то же самое. В остальных местах окна клики проходят сквозь него.
- Если от Джона 5 минут не было событий, шар сам засыпает и снижает частоту кадров
  до 15.

Настройки задаются переменными окружения:

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `JOHN_ORB_PORT` | `47821` | порт моста |
| `JOHN_ORB_SLEEP_MIN` | `5` | через сколько минут тишины шар засыпает |
| `JOHN_ORB_HOTKEY` | `CommandOrControl+Shift+Space` | горячая клавиша |

## Мост

Мост слушает только `127.0.0.1`. Запросы из браузерных страниц отклоняются: у них
есть заголовок `Origin`. Принимаются только имя состояния, символ и уровень звука.
**Текст фраз шар не получает и не хранит.**

```
POST /event  {"state":"processing","symbol":"code"}   {"audio":0.6}
GET  /poll   {"requests":["wake"]}    # горячая клавиша / клик, очищается при чтении
GET  /health {"ok":true,"state":"idle"}
```

## Подключение к Джону (`core/voice_live.py`)

Скопируйте `desktop/john/john_orb.py` в `core/` или добавьте `desktop/john` в
`sys.path`. Клиент использует только стандартную библиотеку. Он не блокирует
вызывающий код и не падает, если шар не запущен.

```python
import john_orb as orb

# в _sleep():
orb.sleeping()

# в _wake():  услышал «Джон»
orb.awake()

# пока пользователь говорит (если есть RMS кадра микрофона):
orb.audio(rms)                      # 0..1, лишние вызовы отбрасываются

# запрос к Хайку отправлен, инструментов ещё нет:
orb.thinking()

# в потоке ответа пришёл tool_use: вызывать ДО выполнения инструмента
orb.tool(block.name)                # memory* → золотой шар; create/code/claude → </>; research/search → сеть

# начал озвучивать или стримить ответ:
orb.talking()

# ответ закончен, Джон ждёт:
orb.idle()

# в главном цикле: пользователь нажал горячую клавишу или кликнул по шару
if orb.wake_requested():
    _wake()
```

Чтобы инструменты Джона попадали в нужный цвет, имена ключей можно поправить в
`TOOL_STATES` в начале `john_orb.py`.
